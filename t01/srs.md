# СРС 1. Свойства алгоритма: примеры нарушений

## 1. Дискретность
* **Исходная формулировка с нарушением:** Почини интернет в колледже.
* **Какое свойство нарушено и почему:** Нарушена дискретность, потому что задача не разбита на мелкие понятные шаги.
* **Исправленная формулировка без нарушения:** 
  1. Вытащить провод из компьютера. 
  2. Подождать 5 секунд. 
  3. Вставить провод обратно.

## 2. Понятность
* **Исходная формулировка с нарушением:** Выполни декомпозицию монолитного бэкенда на микросервисы.
* **Какое свойство нарушено и почему:** Нарушена понятность, исполнитель (студент) не знает этих терминов и не поймет, что делать.
* **Исправленная формулировка без нарушения:** 
  1. Открыть программу Visual Studio. 
  2. Создать новый проект C# Console App. 
  3. Запустить код кнопкой Start.

## 3. Определённость
* **Исходная формулировка с нарушением:** Сдай долг по учебе на этой неделе.
* **Какое свойство нарушено и почему:** Нарушена определённость, так как непонятно, в какой день, во сколько и в каком кабинете искать преподавателя.
* **Исправленная формулировка без нарушения:** 
  1. Прийти в кабинет 305 в четверг. 
  2. Сдать лабу преподавателю ровно в 15:00.

## 4. Результативность
* **Исходная формулировка с нарушением:** Сиди и бесконечно жди, пока загрузится пустая страница без интернета.
* **Какое свойство нарушено и почему:** Нарушена результативность, процесс идет вечно и не имеет конечного итога.
* **Исправленная формулировка без нарушения:** 
  1. Подождать загрузки страницы 10 секунд. 
  2. Если страница не загрузилась, нажать кнопку «Обновить».

## 5. Массовость
* **Исходная формулировка с нарушением:** Инструкция только для студента Аскара: как открыть шкафчик №12 его личным ключом 31 декабря.
* **Какое свойство нарушено и почему:** Нарушена массовость, алгоритм работает только для одного конкретного случая и человека.
* **Исправленная формулировка без нарушения:** 
  Инструкция для любого студента: как открыть шкафчик (вставить ключ, повернуть по часовой стрелке, открыть дверцу).
